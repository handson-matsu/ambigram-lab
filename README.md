# Ambigram Lab

描いて、回して、発見しよう。アンビグラムや自由な絵を描くための静的Webアプリ（Ver.1）です。

## 使い方

`index.html` をブラウザで開くだけで使えます。インストール・ビルド・通信は不要です。

1. 筆・ペン・消しゴム、太さ、色を選び、左のキャンバスに描きます。
2. 右には選択した回転・反転がリアルタイムに表示されます。
3. 「変換して編集」で、プレビューの向きから修正を続けられます。
4. 「画像を保存」で左の作品を白背景の1000 × 1000 PNGとして保存します。

- 筆・ペン・消しゴムの太さはそれぞれ記憶します。
- マウス、タッチ、Apple PencilなどのPointer Events対応ペンに対応。ペンの筆圧を線幅に反映します。
- 最新30操作までUndo / Redoできます。描画1ストローク・全消去・変換して編集がそれぞれ1操作です。
- Undo: Ctrl / Command + Z。Redo: Ctrl / Command + Shift + Z、またはCtrl + Y。
- 作品はブラウザのメモリ内に保持します。再読み込み・ページを閉じる前に画像を保存してください。

## GitHub Pagesで公開

このファイル一式をリポジトリの公開対象ブランチにpushし、GitHubの **Settings → Pages → Deploy from a branch** で対象ブランチと **/ (root)** を選択して保存してください。

相対パスのみ使用しているため、プロジェクト用のGitHub Pagesでもそのまま動作します。

## 構成

- `index.html`: 日本語UI
- `style.css`: レスポンシブデザイン
- `app.js`: Canvas 2Dによる描画・変換・履歴・PNG出力

外部ライブラリ、フォント、API、AIは使用していません。右のキャンバスはプレビュー専用です。
